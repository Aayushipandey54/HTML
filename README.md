# HTML
HTML Projects Repository
Overview
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Welcome to the HTML repository! This repository contains a collection of small websites and projects built with basic HTML. These projects serve as practical examples for beginners who are learning web development or anyone looking for simple HTML templates to explore. Dive into these projects to enhance your web development skills!

Projects
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Below is a list of the HTML files available in this repository:
1. A1.1 Table Tag
File: A1.1table_tage.html
Description: An example demonstrating the use of HTML <table> tags to display tabular data.

2. A1.2 Text Formatting
File: A1.2text_format.html
Description: A project focused on text formatting in HTML using tags like <b>, <i>, <u>, and others to style text.

3. A1.3 List Tags
File: A1.3list_tags.html
Description: Demonstrates how to use ordered lists (<ol>), unordered lists (<ul>), and list items (<li>) in HTML.

4. A1.6 First Page
File: A1.6first_page.html
Description: A simple webpage to introduce HTML basics, including heading tags and paragraph formatting.

5. Academics Page
File: academics.html
Description: A basic HTML webpage showcasing information related to academics, with structured content.

6. Admission Page
File: admission.html
Description: An HTML page layout designed for admission purposes, including forms and structured content.

7. Courses Page
File: courses.html
Description: A webpage layout that displays available courses, using HTML tables and list formatting.

8. External Link Example
File: external.html
Description: Demonstrates how to add external links to your HTML page using the <a> tag.

9. First Page Template
File: first_page.html
Description: A simple HTML template for creating a basic webpage, including a heading, paragraphs, and a link.

10. Index Page (Alternate)
File: index (1).html
Description: An alternate version of an index page for a website.

11. Main Index Page
File: index.html
Description: The main landing page for the website, created as an example of a basic homepage layout.

12. Form Page
File: from.html
Description: An HTML form that collects user input, demonstrating the use of input fields, checkboxes, and buttons.

Features
-----------------------------------------
Basic, easy-to-understand HTML projects
